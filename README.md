# نظام إدارة العملاء - Customer Management System

نظام متكامل لإدارة عملاء الصيانة الدورية مع مزامنة محلية.

## المميزات
- واجهة مدير متكاملة
- واجهة موظف محدودة الصلاحيات  
- نظام تنبيهات تلقائية للمواعيد
- مزامنة بيانات عبر الشبكة المحلية
- تحكم كامل في الترخيص والتحديثات

## التقنيات المستخدمة
- Python
- SQLite
- Tkinter للواجهات
- Socket للاتصال الشبكي

git clone https://github.com/your-username/customer-management-system.git
